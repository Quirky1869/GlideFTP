## 🇬🇧 English

### New Features

#### Native Linux packages (.deb, .rpm, AUR)
GlideFTP is now available as native Linux packages in addition to the existing binary and AppImage distributions:

- **Debian / Ubuntu** - install with `sudo apt install ./GlideFTP-Linux-vX.Y.Z.deb`
- **Fedora / RHEL** - install with `sudo dnf install GlideFTP-Linux-vX.Y.Z.rpm`
- **Arch Linux** - install from the AUR: `yay -S glideftp-bin`

Once installed, GlideFTP appears in your application launcher and is accessible from the command line as `glideftp`.

Releases are now fully automated via GitHub Actions: pushing a version tag builds all packages and creates a draft release automatically.

#### Search in the current folder
Both the local and remote panels now have a search button (magnifying glass) next to the tree-view toggle. Type a name to filter the current folder instantly, or search through all subfolders recursively - recursive search is on by default so results across the whole tree show up right away, and it works the same way in list view and tree view. Double-click a folder result to jump into it, double-click a file to transfer it; rename, transfer, delete and drag-and-drop all work directly from the results list.

#### "New folder" from the right-click menu
The New folder action is no longer limited to the toolbar button. Right-click any file or folder to create a new folder from the context menu too - right-clicking a file always creates the folder in the current directory, while right-clicking a folder asks whether to create it in the current directory or inside the folder you clicked.

#### Selective site export
When clicking "Export sites" in the Site Manager, you can now choose exactly which sites to include before the export dialog appears:

- All sites are pre-selected by default
- A "Select all" checkbox at the top lets you select or deselect everything at once
- Each site has its own checkbox
- Click **Validate** to proceed to the existing export dialog (with or without passwords), or **Cancel** to go back without exporting

#### New setting - double-click to go to the parent folder
A new option in Settings > Interface lets you require a double-click on the ".." row (or the parent-folder toolbar arrow) to navigate up, instead of a single click. Off by default to preserve current behavior; applies to both panels and both view modes.

#### New setting - keep "Manage sites" open on outside click
A new option in Settings > Interface controls whether clicking outside the "Manage sites" modal closes it. Enabled by default (matches current behavior); when disabled, only the ✕ button closes the modal, preventing accidental loss of an in-progress site edit.

#### Refreshed theme toggle icons
The Dark/Light theme toggle in Settings > Appearance now uses clean line-style SVG icons (crescent moon / sun) instead of emoji, matching the rest of the app's icon set.

### Bug Fixes

#### Site export selection panel could stay hidden
In Site Manager, if a site was already selected (its detail panel open) or being edited when you clicked "Export sites," the selection panel (checkboxes + Validate/Cancel) failed to appear - the previously open detail or edit view stayed on screen instead, leaving no way to validate the export. Clicking "Export sites" now always shows the export selection panel, regardless of what was open beforehand.

## 🇫🇷 Français

### Nouvelles fonctionnalités

#### Paquets Linux natifs (.deb, .rpm, AUR)
GlideFTP est désormais disponible sous forme de paquets Linux natifs, en plus du binaire et des AppImages existants :

- **Debian / Ubuntu** - installation avec `sudo apt install ./GlideFTP-Linux-vX.Y.Z.deb`
- **Fedora / RHEL** - installation avec `sudo dnf install GlideFTP-Linux-vX.Y.Z.rpm`
- **Arch Linux** - installation depuis l'AUR : `yay -S glideftp-bin`

Une fois installé, GlideFTP apparaît dans le lanceur d'applications et est accessible en ligne de commande via `glideftp`.

Les releases sont désormais entièrement automatisées via GitHub Actions : pousser un tag de version construit tous les paquets et crée une draft release automatiquement.

#### Recherche dans le dossier courant
Les panneaux local et distant disposent maintenant d'un bouton de recherche (loupe) à côté du bouton de vue arborescente. Tapez un nom pour filtrer instantanément le dossier courant, ou recherchez dans tous les sous-dossiers de façon récursive - la recherche récursive est activée par défaut, si bien que les résultats de tout l'arbre apparaissent immédiatement, et cela fonctionne de la même façon en vue liste et en vue arborescente. Double-cliquez sur un dossier trouvé pour y accéder, double-cliquez sur un fichier pour le transférer ; renommer, transférer, supprimer et le glisser-déposer fonctionnent directement depuis la liste de résultats.

#### "Nouveau dossier" depuis le menu clic droit
L'action Nouveau dossier n'est plus limitée au bouton de la barre d'outils. Un clic droit sur n'importe quel fichier ou dossier permet aussi de créer un nouveau dossier depuis le menu contextuel - un clic droit sur un fichier crée toujours le dossier dans le répertoire courant, tandis qu'un clic droit sur un dossier demande s'il faut le créer dans le répertoire courant ou à l'intérieur du dossier cliqué.

#### Export sélectif des sites
En cliquant sur "Exporter les sites" dans le Gestionnaire de sites, vous pouvez maintenant choisir exactement quels sites inclure avant que le dialogue d'export s'affiche :

- Tous les sites sont pré-sélectionnés par défaut
- Une case "Tout sélectionner" en haut permet de tout sélectionner ou désélectionner en un clic
- Chaque site dispose de sa propre case à cocher
- Cliquez sur **Valider** pour accéder au dialogue d'export existant (avec ou sans mots de passe), ou sur **Annuler** pour revenir sans exporter

#### Nouveau paramètre - double-clic pour aller au dossier parent
Une nouvelle option dans Paramètres > Interface permet d'exiger un double-clic sur la ligne ".." (ou sur la flèche "dossier parent" de la barre d'outils) pour naviguer vers le haut, au lieu d'un simple clic. Désactivé par défaut pour préserver le comportement actuel ; s'applique aux deux panneaux et aux deux modes d'affichage.

#### Nouveau paramètre - garder "Gérer les sites" ouvert en cliquant à côté
Une nouvelle option dans Paramètres > Interface contrôle si un clic en dehors de la fenêtre "Gérer les sites" la ferme. Activé par défaut (comportement actuel inchangé) ; une fois désactivé, seul le bouton ✕ ferme la fenêtre, ce qui évite de perdre accidentellement une modification de site en cours.

#### Icônes du thème actualisées
Le bouton Sombre/Clair dans Paramètres > Apparence utilise désormais des icônes SVG épurées (lune / soleil) au lieu d'émojis, en cohérence avec le reste des icônes de l'application.

### Corrections de bugs

#### Le panneau de sélection d'export des sites pouvait rester caché
Dans le Gestionnaire de sites, si un site était déjà sélectionné (son panneau de détail ouvert) ou en cours de modification au moment de cliquer sur "Exporter les sites", le panneau de sélection (cases à cocher + Valider/Annuler) n'apparaissait pas - le panneau de détail ou d'édition précédemment ouvert restait affiché à la place, sans aucun moyen de valider l'export. Un clic sur "Exporter les sites" affiche désormais toujours le panneau de sélection d'export, quel que soit ce qui était ouvert auparavant.
