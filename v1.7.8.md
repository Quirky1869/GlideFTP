## 🇬🇧 English

### New Features

#### Choose the date format of the file lists
Settings > Interface > Date format is now a dropdown of ready-made formats, each one shown with today's date so you can see exactly what you'll get (e.g. `2026-10-07 14:30`, `07/10/2026 14:30`, `10/07/2026 2:30 PM`, `07 Oct 2026 14:30`), plus a "System default" option that follows your OS locale. The Date column of both file panels updates instantly and resizes itself to fit the chosen format.

#### Advanced mode: write your own date format
Picking "Advanced (custom)…" in the dropdown reveals a text field where you can type your own pattern, with a live preview underneath. Hovering the small "i" button next to the field lists every available variable - for example `%dd` day, `%MM` month, `%yyyy` year, `%hh` hours, `%mm` minutes, `%ss` seconds, `%MMM` short month name, `%I`/`%p` 12-hour clock with AM/PM. Variables are case-sensitive: uppercase `M` is the month, lowercase `m` is the minutes.

#### Renaming selects the name without the extension
When renaming a file (F2 or right-click > Rename), only the name is now pre-selected, not its extension - type the new name and `.pdf`, `.txt`, etc. are kept. Folders still have their whole name selected. Same behavior in the "Rename" step of the file-conflict dialog.

#### "Cancel all" button in the transfer queue
Dropping a big folder (a git repository, for instance) can queue thousands of files - there was no way to stop it short of cancelling them one by one. A new red "Cancel all" button in the transfer queue's "Pending" tab stops everything at once: running transfers are interrupted, waiting ones are cancelled, and a folder still being scanned stops adding new files immediately.

#### Window size shown while resizing
Resizing the window now shows its current size (e.g. `1400 × 900`) in the middle of the screen, and fades out right after. It's framed in your accent color, with the accent glow only if the accent shadow is enabled in Settings. Handy to find the right values for Settings > Window width / height, which set the window size at startup. Even simpler: the new "Use current size" button in Settings (below Window height) fills both fields with the current window size and saves it in one click.

#### Accent color gradient
The accent color can now be a gradient. In Settings > Color, a new "Gradient" switch at the top of the color picker (off by default - the picker then looks exactly as before) reveals a second color under the main one - each color in its own clearly separated block - with the same interactive palette, HEX and RGB fields and its own recent colors. A "Recent gradients" row under the gradient preview restores your last 8 color pairs in one click. The gradient is applied across the whole app: buttons, switches, badges, progress bars, selected rows, titles and accent text, tab underlines, popup borders, and the connection panel's shadow box.

#### Open files with their default application
A new "Open" entry in the right-click menu of any file opens it with your system's default application - text, images, PDF, videos, documents... Remote files are downloaded to a temporary folder first (with a progress bar showing the percentage, speed and time left, and a Cancel button), and GlideFTP watches them: each time you save one, it offers to send it back to the server (Yes / No / Always for this file). If the file was changed on the server in the meantime, you're warned before overwriting it. If no application is associated with the file type, you can choose one, download the file to the local folder, or open the containing folder (Windows shows its native "Open with" dialog). Quitting with modified files not sent back asks for confirmation.

#### Quick connect from the site list
Each saved site in the Site Manager now has a small arrow button at the end of its row: one click connects to it directly, without opening its details first. It lights up in your accent color on hover.

#### Search results: go to location / copy path
Right-clicking a search result now offers "Go to location" (opens the folder containing the file, with the file selected - or the folder itself for a folder) and "Copy path" (the containing folder's path for a file, the folder's own path for a folder).

#### Faster searches with a local cache of your server's folders (optional)
GlideFTP can now remember the content of the remote folders it has already gone through (during searches and normal browsing), so your next searches check the known locations first: a file seen before shows up within seconds, while the full search continues to find what's new. Every result is checked on the server first - a deleted or moved file is never shown, and the cache is updated. This option is off by default: a window explains it the first time you launch GlideFTP, and you can turn it on or off, see these explanations again (the "?" button) or clear the cache at any time in Settings > Search. The cache contains the names, sizes and dates of your remote files (never passwords or file contents) and is stored in:
- Linux: `~/.cache/GlideFTP/search-index/`
- Windows: `%LOCALAPPDATA%\GlideFTP\search-index\`

The cache files are protected: a file modified outside GlideFTP is detected and discarded instead of being used, and on Windows they are locked while GlideFTP runs (other programs can't open, modify, delete or rename them).

#### Only one GlideFTP at a time
Launching GlideFTP while it's already running now simply brings back the open window instead of starting a second copy.

### Bug Fixes

#### The "Date format" setting had no effect
The old free-text "Date format" field was saved but never actually used - the file lists always displayed dates in the system locale format, whatever you typed. The setting is now applied to the Date column. Existing settings files are migrated automatically to the new default format (`2026-10-07 14:30` style).

#### No message after Copy / Cut in the file panels
Copying or cutting files (Ctrl+C / Ctrl+X or the right-click menu) worked but gave no feedback - the green message only appeared after pasting. Copy and Cut now show a confirmation too (e.g. `"report.pdf" copied - Ctrl+V to paste` or `3 items cut - Ctrl+V to paste`).

#### Cancelling a waiting transfer didn't stop it
Clicking "Cancel" on a transfer still waiting in the queue marked it as cancelled, but the file was transferred anyway as soon as a slot freed up. Cancelled transfers are now really skipped.

#### Window limited to the size of the first screen (Linux / Hyprland)
On Hyprland, the window couldn't get bigger than the screen it was opened on - for instance, opened on a 1920x1200 laptop screen, it stayed at 1920x1200 even maximized on a larger ultrawide monitor. It can now fill any screen.

#### Remote search disconnected from the server and missed files
Searching in the remote panel could break the FTP session - afterwards you couldn't open a folder or rename anything without reconnecting by hand - and show "no results" even for files that were there. The search was walking into the FTP server's system folders, several searches ran in parallel while typing, and errors were hidden. Search is now much faster: several folders are listed in parallel, nearby folders first, the FTP server's system folders are skipped, and results appear as soon as they're found (with a running count of folders searched) instead of only at the end. Only one search runs at a time (cancelled as soon as you type more or close it), a note tells you when results are partial, and errors are shown. Above all, when an FTP server closes the session, GlideFTP now reconnects automatically and retries the command instead of staying stuck on a dead connection.

## 🇫🇷 Français

### Nouvelles fonctionnalités

#### Choisir le format de date des listes de fichiers
Paramètres > Interface > Format de date est désormais une liste déroulante de formats prêts à l'emploi, chacun affiché avec la date du jour pour voir exactement le rendu (par exemple `2026-10-07 14:30`, `07/10/2026 14:30`, `10/07/2026 2:30 PM`, `07 oct. 2026 14:30`), ainsi qu'une option "Format du système" qui suit la langue de votre OS. La colonne Date des deux panneaux se met à jour immédiatement et s'élargit automatiquement selon le format choisi.

#### Mode avancé : créer son propre format de date
Choisir "Avancé (personnalisé)…" dans la liste affiche un champ texte pour saisir votre propre modèle, avec un aperçu en direct juste en dessous. Survoler le petit bouton "i" à côté du champ affiche toutes les variables disponibles - par exemple `%dd` jour, `%MM` mois, `%yyyy` année, `%hh` heures, `%mm` minutes, `%ss` secondes, `%MMM` nom du mois abrégé, `%I`/`%p` heure sur 12h avec AM/PM. Les variables sont sensibles à la casse : `M` majuscule pour le mois, `m` minuscule pour les minutes.

#### Le renommage sélectionne le nom sans l'extension
Lors du renommage d'un fichier (F2 ou clic droit > Renommer), seul le nom est maintenant présélectionné, sans son extension - tapez le nouveau nom et `.pdf`, `.txt`, etc. sont conservés. Les dossiers ont toujours leur nom entier sélectionné. Même comportement à l'étape "Renommer" de la fenêtre de conflit de fichiers.

#### Bouton "Tout annuler" dans la file d'attente
Déposer un gros dossier (un dépôt git par exemple) peut mettre des milliers de fichiers en file d'attente - impossible de l'arrêter autrement qu'en les annulant un par un. Un nouveau bouton rouge "Tout annuler" dans l'onglet "En attente" de la file arrête tout d'un coup : les transferts en cours sont interrompus, ceux en attente sont annulés, et un dossier encore en cours d'analyse cesse immédiatement d'ajouter de nouveaux fichiers.

#### Taille de la fenêtre affichée pendant le redimensionnement
Redimensionner la fenêtre affiche maintenant sa taille actuelle (par exemple `1400 × 900`) au centre de l'écran, et qui s'efface l'instant d'après. Elle est encadrée de votre couleur d'accentuation, avec le halo d'accentuation seulement si l'ombre d'accentuation est activée dans les Paramètres. Pratique pour trouver les bonnes valeurs de Paramètres > Largeur / Hauteur de fenêtre, qui définissent la taille à l'ouverture. Encore plus simple : le nouveau bouton "Utiliser la taille actuelle" dans les Paramètres (sous Hauteur de fenêtre) remplit les deux champs avec la taille actuelle de la fenêtre et l'enregistre en un clic.

#### Dégradé pour la couleur d'accentuation
La couleur d'accentuation peut maintenant être un dégradé. Dans Paramètres > Couleur, un nouvel interrupteur "Dégradé" en haut du sélecteur de couleur (désactivé par défaut - le sélecteur reste alors identique) affiche une deuxième couleur sous la couleur principale - chaque couleur dans son propre bloc bien séparé - avec la même palette interactive, ses champs HEX et RGB et ses propres couleurs récentes. Une ligne "Dégradés récents" sous l'aperçu du dégradé permet de retrouver vos 8 derniers couples de couleurs en un clic. Le dégradé s'applique dans toute l'application : boutons, interrupteurs, badges, barres de progression, lignes sélectionnées, titres et textes d'accentuation, soulignement des onglets, bordures des fenêtres, et ombre du panneau de connexion.

#### Ouvrir les fichiers avec leur application par défaut
Une nouvelle entrée "Ouvrir" dans le menu clic droit des fichiers les ouvre avec l'application par défaut de votre système - textes, images, PDF, vidéos, documents... Les fichiers distants sont d'abord téléchargés dans un dossier temporaire (avec une barre de progression indiquant le pourcentage, la vitesse et le temps restant, et un bouton Annuler), puis surveillés : à chaque enregistrement, GlideFTP propose de les renvoyer sur le serveur (Oui / Non / Toujours pour ce fichier). Si le fichier a été modifié sur le serveur entre-temps, un avertissement s'affiche avant de l'écraser. Si aucune application n'est associée au type de fichier, vous pouvez en choisir une, télécharger le fichier dans le dossier local, ou ouvrir le dossier qui le contient (Windows affiche sa fenêtre native "Ouvrir avec"). Quitter avec des fichiers modifiés non renvoyés demande une confirmation.

#### Connexion rapide depuis la liste des sites
Chaque site enregistré dans le Gestionnaire de sites a maintenant un petit bouton flèche au bout de sa ligne : un clic s'y connecte directement, sans ouvrir ses détails. Il s'allume à votre couleur d'accentuation au survol.

#### Résultats de recherche : aller à l'emplacement / copier le chemin
Un clic droit sur un résultat de recherche propose maintenant "Aller à l'emplacement" (ouvre le dossier qui contient le fichier, avec le fichier sélectionné - ou le dossier lui-même pour un dossier) et "Copier le chemin" (le chemin du dossier qui contient le fichier, ou celui du dossier lui-même).

#### Recherches plus rapides grâce à un cache local des dossiers de vos serveurs (optionnel)
GlideFTP peut maintenant mémoriser le contenu des dossiers distants qu'il a déjà parcourus (pendant les recherches et la navigation normale) : vos recherches suivantes vont d'abord voir les emplacements connus, un fichier déjà vu s'affiche en quelques secondes, et la recherche complète continue pour trouver les nouveautés. Chaque résultat est d'abord vérifié sur le serveur - un fichier supprimé ou déplacé n'est jamais affiché, et le cache est mis à jour. L'option est désactivée par défaut : une fenêtre l'explique au premier lancement de GlideFTP, et vous pouvez l'activer ou la désactiver, revoir ces explications (bouton "?") ou vider le cache à tout moment dans Paramètres > Recherche. Le cache contient les noms, tailles et dates de vos fichiers distants (jamais de mot de passe ni de contenu de fichier) et se trouve dans :
- Linux : `~/.cache/GlideFTP/search-index/`
- Windows : `%LOCALAPPDATA%\GlideFTP\search-index\`

Les fichiers du cache sont protégés : un fichier modifié en dehors de GlideFTP est détecté et écarté au lieu d'être utilisé, et sous Windows ils sont verrouillés tant que GlideFTP tourne (les autres programmes ne peuvent ni les ouvrir, ni les modifier, ni les supprimer, ni les renommer).

#### Un seul GlideFTP à la fois
Lancer GlideFTP alors qu'il est déjà ouvert ramène maintenant simplement la fenêtre existante au lieu d'en démarrer une deuxième copie.

### Corrections de bugs

#### Le paramètre "Format de date" n'avait aucun effet
L'ancien champ texte "Format de date" était enregistré mais jamais utilisé - les listes de fichiers affichaient toujours les dates au format de la langue du système, quelle que soit la valeur saisie. Le paramètre est maintenant appliqué à la colonne Date. Les fichiers de paramètres existants sont convertis automatiquement vers le nouveau format par défaut (style `2026-10-07 14:30`).

#### Aucun message après Copier / Couper dans les panneaux de fichiers
Copier ou couper des fichiers (Ctrl+C / Ctrl+X ou le menu clic droit) fonctionnait mais sans aucun retour visuel - le message vert n'apparaissait qu'après avoir collé. Copier et Couper affichent désormais eux aussi une confirmation (par exemple `"rapport.pdf" copié - Ctrl+V pour coller` ou `3 éléments coupés - Ctrl+V pour coller`).

#### Annuler un transfert en attente ne l'arrêtait pas
Cliquer sur "Annuler" sur un transfert encore en attente le marquait comme annulé, mais le fichier était quand même transféré dès qu'une place se libérait. Les transferts annulés sont maintenant réellement ignorés.

#### Fenêtre limitée à la taille du premier écran (Linux / Hyprland)
Sous Hyprland, la fenêtre ne pouvait pas dépasser la taille de l'écran sur lequel elle s'ouvrait - par exemple, ouverte sur un écran de portable 1920x1200, elle restait en 1920x1200 même maximisée sur un écran ultra-large plus grand. Elle peut maintenant remplir n'importe quel écran.

#### La recherche distante déconnectait du serveur et ne trouvait pas les fichiers
Rechercher dans le panneau distant pouvait casser la session FTP - impossible ensuite d'ouvrir un dossier ou de renommer sans se reconnecter à la main - et afficher "aucun résultat" même pour des fichiers bien présents. La recherche parcourait les dossiers système du serbveur FTP, plusieurs recherches tournaient en parallèle pendant la saisie, et les erreurs étaient masquées. La recherche est aussi beaucoup plus rapide : plusieurs dossiers sont listés en parallèle, les plus proches d'abord, les dossiers système du serveur FTP sont ignorés, et les résultats s'affichent dès qu'ils sont trouvés (avec le nombre de dossiers parcourus) au lieu de seulement à la fin. Une seule recherche tourne à la fois (annulée dès que vous tapez la suite ou fermez la recherche), une note signale les résultats partiels, et les erreurs s'affichent. Surtout, quand un serveur FTP ferme la session, GlideFTP se reconnecte maintenant automatiquement et relance la commande au lieu de rester bloqué sur une connexion morte.
