## 🇬🇧 English

### New Features

#### Sound notification when the transfer queue finishes
GlideFTP can now play a short sound once the transfer queue is fully done - uploads and downloads alike, one sound per batch rather than one per file. It's off by default - enable it in Settings > Notifications with a simple on/off switch. Once enabled, a dropdown lets you pick from four soft, purpose-made notification sounds (Chime, Bell, Pop, Glass), and a speaker button next to it lets you preview any sound before choosing it. The sound plays at whatever volume your system/app mixer is set to - there is no separate in-app volume control.

#### Reorder saved sites via drag-and-drop
A new toggle button next to "+ New site" in the Site Manager switches the list into reorder mode: each site gets a drag handle, and you can drag rows into any order you like. Click the button again to confirm and exit reorder mode. The new order is saved immediately and persists across restarts.

#### Export / import all Settings as a JSON file
The entire Settings page can now be exported to a JSON file and imported back - handy for carrying the exact same configuration over to a different PC. Two small icon buttons in the Settings panel footer (next to the version badge) handle export and import; importing applies the new settings immediately, no restart required.

#### Themed notification pop-up
Success and error messages (from exporting/importing sites or settings, connection failures, etc.) now use a themed pop-up matching the app's accent color, translated in your current language - replacing the old unstyled native browser alert box.

### Bug Fixes

#### Delete key did nothing after a rubber-band (click-drag) selection
Selecting several files/folders by dragging a selection box and then pressing Delete had no effect - only Ctrl+click and Shift+click selections worked with the Delete key. All selection methods now work identically.

#### Ugly layout for the delete-site confirmation in Site Manager
Clicking "Delete site" showed the confirmation text and Yes/No buttons crammed unevenly into the same row as Connect/Edit site. The confirmation now appears as its own centered block below, with the Yes/No buttons centered on their own row underneath.

#### Environment variables and `~` not expanded in local paths
Typing a path containing an environment variable - e.g. `C:\Users\%USERNAME%\Desktop`, `$USER/$HOME`, or `~` - into the "Default local directory" setting was not resolved. This is now expanded correctly. Also fixed: saving a new "Default local directory" now navigates the local panel there immediately, without needing to restart the app.

#### Settings "reset" button always showing, even at the default value
The small `↺` reset button next to each setting used to stay visible all the time, even when that setting was already at its factory default. It now only appears once the value has actually been changed, and disappears again as soon as it matches the default.

## 🇫🇷 Français

### Nouvelles fonctionnalités

#### Son de notification à la fin de la file d'attente
GlideFTP peut désormais jouer un son court une fois que la file d'attente des transferts est entièrement terminée - uploads et downloads confondus, un seul son par lot plutôt qu'un par fichier. Cette option est désactivée par défaut - activez-la dans Paramètres > Notifications avec un simple interrupteur on/off. Une fois activée, une liste déroulante permet de choisir parmi quatre sons de notification doux créés pour l'application (Carillon, Cloche, Pop, Verre), et un bouton haut-parleur à côté permet d'écouter chaque son avant de le choisir. Le son est joué au volume défini par le mixage système/application - il n'y a pas de réglage de volume séparé dans l'application.

#### Réorganiser les sites enregistrés par glisser-déposer
Un nouveau bouton à côté de "+ Nouveau site" dans le Gestionnaire de sites bascule la liste en mode réorganisation : chaque site affiche une poignée de glisser, et vous pouvez déplacer les lignes dans l'ordre souhaité. Cliquez à nouveau sur le bouton pour confirmer et quitter le mode réorganisation. Le nouvel ordre est enregistré immédiatement et conservé après redémarrage.

#### Exporter / importer tous les paramètres en JSON
L'ensemble de la page Paramètres peut désormais être exporté vers un fichier JSON puis réimporté - pratique pour retrouver exactement la même configuration sur un autre PC. Deux petits boutons icônes dans le pied de page des Paramètres (à côté du badge de version) gèrent l'export et l'import ; l'import applique immédiatement les nouveaux paramètres, sans redémarrage.

#### Pop-up de notification aux couleurs de l'application
Les messages de succès et d'erreur (export/import des sites ou des paramètres, échecs de connexion, etc.) utilisent désormais une pop-up aux couleurs d'accentuation de l'application, traduite dans votre langue actuelle - remplaçant l'ancienne boîte d'alerte native du navigateur, non stylisée.

### Corrections de bugs

#### La touche Suppr ne faisait rien après une sélection par glisser (rubber-band)
Sélectionner plusieurs fichiers/dossiers en faisant glisser un rectangle de sélection puis appuyer sur Suppr n'avait aucun effet - seules les sélections par Ctrl+clic et Shift+clic fonctionnaient avec la touche Suppr. Toutes les méthodes de sélection fonctionnent désormais de façon identique.

#### Mise en page maladroite de la confirmation de suppression de site
Cliquer sur "Supprimer le site" affichait le texte de confirmation et les boutons Oui/Non entassés de façon inégale sur la même ligne que Connecter/Modifier le site. La confirmation apparaît maintenant dans son propre bloc centré en dessous, avec les boutons Oui/Non centrés sur leur propre ligne.

#### Variables d'environnement et `~` non résolues dans les chemins locaux
Saisir un chemin contenant une variable d'environnement - par exemple `C:\Users\%USERNAME%\Desktop`, `$USER/$HOME`, ou `~` - dans le paramètre "Répertoire local par défaut" n'était pas résolu. C'est désormais corrigé. Également corrigé : enregistrer un nouveau "Répertoire local par défaut" navigue immédiatement le panneau local vers ce dossier, sans avoir besoin de redémarrer l'application.

#### Bouton de réinitialisation des paramètres toujours affiché, même à la valeur par défaut
Le petit bouton `↺` à côté de chaque paramètre restait affiché en permanence, même quand ce paramètre était déjà à sa valeur d'usine. Il n'apparaît désormais que lorsque la valeur a réellement été modifiée, et disparaît à nouveau dès qu'elle correspond de nouveau au défaut.
