## 🇬🇧 English

### New Features

#### Save a site directly from the connection screen
The connection screen now has a save button (floppy disk) to the left of "Protocol", greyed out like the connect button until a host is typed. One click saves the server you just typed (protocol, host, port, user, password) to "Manage sites", named `user@host`. The password is stored in the system keyring, like for any other site. If the same server/user is already saved, you're told so instead of getting a duplicate. The confirmation has an "Open sites" button that opens "Manage sites" directly on the saved site. The Host field's example now shows both a domain and an IP address (`site.com / 10.0.0.1`).

#### Resizable columns in the file lists
The Name, Size and Date columns of both panels (local and remote) can now be resized: drag the small divider at the right of a column header. Double-clicking that divider fits the column to the longest name, size or date currently listed. Widths are remembered separately for each panel; when the columns are wider than the panel, the list scrolls horizontally.

#### See the full list before deleting several items
When deleting several files/folders, the confirmation still shows "N items", which can now be clicked to unfold the list of every selected file and folder, so you can check exactly what is about to be deleted. While deleting, the "Delete" button shows the progress (1/2, 2/2...) and the window closes once it's done. The "Delete" button is now focused when the confirmation opens: Enter confirms, Escape cancels.

#### Your own sound for the end of transfers
Settings > Notifications now has a "Load a custom sound" button (music note) next to the test button: pick any audio file (mp3, wav, ogg, opus, flac, m4a, aac, webm, 10 MB max) and it becomes the end-of-transfer sound, listed as "Custom: <file name>" in the sound list. The file is copied into GlideFTP's settings folder, so you can move or delete the original. Sounds are played for 5 seconds at most, with a short fade-out, if your file is longer, you're told only the first 5 seconds will be played. A trash button removes the custom sound.

#### Show the password while typing it
The password field of the connection screen now has an eye button, shown as soon as you type, to display the password in clear and check it before connecting.

#### Option to hide the window size while resizing
The "width × height" box shown in the middle of the window while you resize it can now be turned off: Settings > Interface > "Show size while resizing". It stays on by default.

#### Explanations in the settings
"Max concurrent transfers", "Operation timeout" and "Max simultaneous connections" now have a "?": hover over it to see what the setting does. The "Passive mode (PASV)" and "Auto-reconnect" switches are gone: they had no effect (GlideFTP always uses passive mode, and the FTP connection already reconnects on its own when the server closes it).

---

### Bug Fixes

#### Shift+click highlighted the file names like selected text
Selecting a range of files/folders with Shift+click also highlighted the names, sizes and dates in the list as if they were selected text. Only the rows are now highlighted.

#### FTP: an action could freeze, then the server got disconnected
When an FTP server (or the router in between) stopped answering without closing the connection, an action such as a delete waited forever: nothing happened, every following action was stuck too, and the server ended up disconnected. GlideFTP now gives up after the "Operation timeout" set in the settings, reconnects on its own and retries once. A folder that is slow to list while another action is running no longer disconnects the server either.

---

### Packaging

#### Windows: the .exe directly, or a .7z archive
Windows downloads are no longer `.tar` / `.tar.gz` archives (awkward to open on Windows): the release now offers the executable itself (`GlideFTP-Windows-v1.7.9.exe`), ready to run, and a `.7z` archive containing it.

## 🇫🇷 Français

### Nouvelles fonctionnalités

#### Enregistrer un site directement depuis l'écran de connexion
L'écran de connexion a maintenant un bouton d'enregistrement (disquette) à gauche de "Protocole", grisé comme le bouton de connexion tant qu'aucun hôte n'est saisi. Un clic enregistre le serveur saisi (protocole, hôte, port, utilisateur, mot de passe) dans "Gérer les sites", sous le nom `utilisateur@hôte`. Le mot de passe est stocké dans le keyring système, comme pour tous les autres sites. Si le même serveur/utilisateur est déjà enregistré, un message vous le signale au lieu de créer un doublon. La confirmation propose un bouton "Ouvrir les sites" qui ouvre "Gérer les sites" directement sur le site enregistré. L'exemple du champ Hôte montre maintenant un domaine et une adresse IP (`site.com / 10.0.0.1`).

#### Colonnes redimensionnables dans les listes de fichiers
Les colonnes Nom, Taille et Date des deux panneaux (hôte et distant) peuvent maintenant être redimensionnées : faites glisser le petit séparateur à droite de l'en-tête d'une colonne. Un double-clic sur ce séparateur ajuste la colonne au nom, à la taille ou à la date le plus long actuellement affiché. Les largeurs sont mémorisées séparément pour chaque panneau ; quand les colonnes sont plus larges que le panneau, la liste défile horizontalement.

#### Voir la liste complète avant de supprimer plusieurs éléments
Lors de la suppression de plusieurs fichiers/dossiers, la confirmation affiche toujours "N éléments", sur lequel on peut maintenant cliquer pour déplier la liste de tous les fichiers et dossiers sélectionnés pour vérifier exactement ce qui va être supprimé. Pendant la suppression, le bouton "Supprimer" affiche la progression (1/2, 2/2...) et la fenêtre se ferme une fois terminé. Le bouton "Supprimer" a maintenant le focus à l'ouverture de la confirmation : Entrée confirme, Échap annule.

#### Votre propre son de fin de transfert
Paramètres > Notifications propose maintenant un bouton "Charger un son personnalisé" (note de musique) à côté du bouton de test : choisissez n'importe quel fichier audio (mp3, wav, ogg, opus, flac, m4a, aac, webm, 10 Mo maximum) et il devient le son de fin de transfert, affiché "Personnalisé : <nom du fichier>" dans la liste des sons. Le fichier est copié dans le dossier de configuration de GlideFTP, vous pouvez donc déplacer ou supprimer l'original. Les sons sont joués 5 secondes au maximum, avec un court fondu - si votre fichier est plus long, un message vous indique que seules les 5 premières secondes seront jouées. Un bouton corbeille supprime le son personnalisé.

#### Afficher le mot de passe pendant la saisie
Le champ mot de passe de l'écran de connexion a maintenant un bouton œil, affiché dès que vous tapez, pour voir le mot de passe en clair et le vérifier avant de vous connecter.

#### Option pour masquer la taille de la fenêtre pendant le redimensionnement
Le cadre "largeur × hauteur" affiché au milieu de la fenêtre pendant que vous la redimensionnez peut maintenant être désactivé : Paramètres > Interface > "Afficher la taille pendant le redimensionnement". Il reste activé par défaut.

#### Explications dans les paramètres
"Transferts simultanés maximum", "Délai d'opération" et "Connexions simultanées max" ont maintenant un "?" : passez la souris dessus pour voir à quoi sert le réglage. Les interrupteurs "Mode passif (PASV)" et "Reconnexion automatique" ont été retirés : ils n'avaient aucun effet (GlideFTP utilise toujours le mode passif, et la connexion FTP se rétablit déjà toute seule quand le serveur la coupe).

---

### Corrections de bugs

#### Shift+clic surlignait les noms de fichiers comme du texte sélectionné
Sélectionner une plage de fichiers/dossiers avec Shift+clic surlignait aussi les noms, tailles et dates de la liste comme s'il s'agissait de texte sélectionné. Seules les lignes sont maintenant mises en surbrillance.

#### FTP : une action pouvait rester bloquée, puis le serveur était déconnecté
Quand un serveur FTP (ou le routeur entre les deux) arrêtait de répondre sans fermer la connexion, une action comme une suppression attendait indéfiniment : il ne se passait rien, toutes les actions suivantes restaient bloquées elles aussi, et le serveur finissait déconnecté. GlideFTP abandonne maintenant au bout du "Délai d'opération" réglé dans les paramètres, se reconnecte tout seul et réessaie une fois. Un dossier long à lister pendant qu'une autre action est en cours ne déconnecte plus le serveur non plus.
